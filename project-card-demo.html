3. Fitur & Karakteristik

📱 Responsive Design
Komponen ini fully responsive dan cocok untuk semua ukuran layar. Menggunakan CSS Grid dengan auto-fit untuk adaptasi otomatis.
🎨 Modern Styling
Desain modern dengan gradient, glassmorphism effect, dan color scheme yang cocok untuk portfolio developer (cyber/neon theme).
✨ Smooth Animations
Menggunakan cubic-bezier untuk animasi yang natural dan smooth. Efek hover mencakup zoom gambar, overlay transition, dan button effects.
♿ Accessibility
Support untuk keyboard navigation, focus states, dan prefers-reduced-motion untuk pengguna yang sensitif terhadap animasi.
⚡ Performance
CSS-only animations (no JavaScript) menghasilkan performance yang excellent. Menggunakan transform dan opacity untuk optimal rendering.

4. Customization Tips

🎯 Mengubah Warna:
Ganti nilai warna #00ffff (cyan) dengan warna pilihan Anda. Utama ditemukan di: overlay color, link buttons, borders, dan text-shadow.
📐 Mengubah Ukuran:
Aspect ratio image container: aspect-ratio: 16 / 10 (ubah untuk ratio berbeda)
Border radius: ubah nilai pada .project-card dan .project-img
🔧 Mengubah Animasi:
Kecepatan transition default: 0.4s. Ubah di CSS untuk kecepatan berbeda.
Transform effects: scale(1.08) untuk zoom strength, translateY(-8px) untuk card lift.
🏷️ Menambah/Mengurangi Links:
Tambah atau kurangi <a> tag di .project-links sesuai kebutuhan.
